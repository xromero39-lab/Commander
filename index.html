CommandForge Help

Search: Type a card name, or use Scryfall searches like t:elf, o:draw, or id:ug.

Add cards: Drag a card from the Library to Main Deck or Side/Maybe Deck. You can also use the “+ Deck” and “+ Side” buttons.

Move cards: Drag deck rows between Main Deck and Side/Maybe Deck. Use the minus button to remove one copy.

Custom tokens: Upload your own image, add a name/types/power-toughness/rules text, then drag the token into either zone as a visual reference.

Save: This prototype saves on this browser and Mac using local browser storage. It is not yet cloud-synced.
